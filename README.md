# 🩺 Diabetes Prediction System

An end-to-end Machine Learning web application to predict diabetes risk using the PIMA Indians Diabetes Dataset.

## Tech Stack
- Machine Learning: Scikit-Learn
- Backend: FastAPI
- Frontend: Streamlit
